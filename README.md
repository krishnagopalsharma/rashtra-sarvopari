## 📌 About

**Rashtra Sarvopari** is a civic dashboard prototype built for citizens of **Govardhan Tehsil, Mathura District, Uttar Pradesh** to report and track local issues like roads, water, electricity, and sanitation.

> ⚠️ **Current Status: Paused** — Core UI is complete. Further development paused due to resource constraints (backend storage, moderation system) and legal considerations around user-generated content about public representatives.

## ✨ Features Built

- 📍 **Area Board** — Select State → District → Tehsil or use GPS location
- 📝 **Issue Reporting** — Report local civic problems in your area
- 🗳️ **Voting & Opinions** — Vote and comment on reported issues
- 🧑‍💼 **Representatives** — View local area representatives
- 👤 **Citizen Profile** — Create profile with name and photo
- 🗺️ **Govardhan Map** — Local area map integration
- 🔐 **Profile Moderation** — Basic content moderation system
- ⚡ **Serverless Backend** — Netlify Functions + Netlify Blobs

## 🧠 Problem Statement

Citizens of Govardhan Tehsil, Mathura have no easy digital way to:
- Report local civic problems (roads, water, electricity, sanitation)
- See issues raised by others in their area
- Connect problems to their local representatives

Rashtra Sarvopari was built to solve this gap.

---

## ⚠️ Why Paused

- Backend storage costs on free tier are limiting
- Image uploads not working due to size constraints
- Need a proper content moderation system before public launch
- Legal risks around user-generated content about public figures
- Need team support to scale further
